# 로그캘린더 · 음성 제목 · 최근 프리셋 (2026-10-21)

상단 메뉴 후속: ‘로그캘린더’ 텍스트는 제거하고 스튜디오 오른쪽에 44px 원형 달력 아이콘(CalendarDays, 단색 1.7px 선)으로 배치했다. 설정은 그 오른쪽의 기존 오버레이 버튼이다. 선택 표시·접근성 이름·툴팁은 유지하며 초기 가이드와 메뉴 전환 방향을 맞췄다. 스튜디오 왼쪽 스와이프 경계는 유지한다.

## 요청과 적용

| 요청 | 현재 동작 |
| --- | --- |
| 음성 제목 후보 | 확정된 음성의 첫 문장을 최대 28자 전후로 줄여 제안. 제목이 비어 있을 때만 보이고, 눌러야 입력. 본문/수동 제목 보존, AI/유료 요청 없음 |
| 마이크 아이콘 | 내용 아래 반투명 원형 마이크 하나. 인식 중에는 정지 아이콘과 듣기 상태를 표시. 46px 터치 영역/aria-label/권한·오류 대안 유지 |
| 최근 프리셋 3개 | 카드 편집 창에 실제 카드 썸네일 3개. 선택한 프리셋을 앞에 보여주며 전체 보관함/화살표 유지. 이력이 없으면 호환되는 프리셋으로 빠른 선택 제공 |
| 로그캘린더 메뉴 | 모바일 위 달력·아래 지도, 900px 이상 또는 넓은 가로 화면은 좌우 배치. 작은 화면에서 상단 메뉴는 ‘캘린더’로 축약 |
| 날짜별 대표 사진 | 해당 날짜의 마지막 사진 로그를 대표 사진으로 표시. 여러 로그는 개수 배지. 사진 없는 날도 날짜/로그 탐색 가능 |
| 날짜/기간 선택 | 하루를 누르거나 시작·종료일 지정. 양 끝 날짜 포함, 역순 입력은 정렬. 시간순 로그를 달력 위 오버레이로 펼쳐 표시 |
| 시간별 목록과 이동 | 날짜 섹션·업로드 시각·사진·제목·장소 표시. 항목을 누르면 해당 카드로 이동. 캘린더로 돌아오면 달/날짜·기간/오버레이 상태 유지 |
| 지도 경로 | 로그북과 같은 Leaflet + OpenStreetMap/다크 필터. 선택 범위의 유효 좌표를 시간순으로 연결, 번호 핀·선 그리기·빛 이동. 재생 버튼 제공 |

## 데이터와 동작 경계

- 날짜와 시각은 기존 앱의 `Asia/Seoul` 업로드 시각 기준이다. 하루는 KST 자정 기준이며 본문 수정으로 업로드 시각을 바꾸지 않는다. 그룹은 원본 로그를 중복 집계하지 않도록 달력에서 제외한다.
- 캘린더는 기존 `ArchiveItem`의 timestamp/img/coordinates를 읽는다. 새 테이블·DB 마이그레이션·이미지 복제·추가 업로드는 없다. 위치 없는 로그도 시간 목록에는 포함하고 지도 선에서는 제외한다.
- 지도 선은 **저장한 장소 좌표를 순서대로 연결한 선**이다. GPS 추적이나 실제 도로 안내 경로가 아니다. 추가 Google 검색/경로 API를 호출하지 않는다. OSM 출처 표시를 유지한다.
- 최근 프리셋은 `l2_recent_presets_v1:<deviceId>` 키에 최대 12개 ID를 기기별로 보관하고 3개만 노출한다. 계정 범위가 달라지면 이력을 분리한다. 서버/다른 기기에 동기화되는 설정은 아니며, 개별 카드와 원본 프리셋은 기존대로 분리된다. 삭제되었거나 일반/그룹 로그와 호환되지 않는 프리셋은 후보에서 제외한다.
- 캘린더 날짜 선택·범위 입력·이전/다음 달·연월 바로 선택·오늘·월 전체 보기 제공. 날짜 버튼은 방향키로도 이동하며 월 경계를 넘어간다. 오버레이는 닫기/Escape를 제공하고 목록은 내부 스크롤, 80개씩 추가 표시한다.
- 오버레이는 지도와 함께 사용하는 비모달 영역이다. 덮인 달력은 inert로 잠그고, 지도 조작은 가능하다. 별도의 기간·연월 모달은 기존 AccessibleDialog의 포커스/배경 처리 사용. 첫 사용자 가이드도 새 메뉴와 기능에 맞췄다.

## 모션과 회귀 수정

- 달력 오버레이가 아래에서 펼쳐지고 로그 항목은 순차 등장한다. 경로는 최대 약 5초 동안 주황색 선과 이동하는 빛으로 그린다. 한 번 재생한 뒤 정지하며 재생 버튼으로 반복할 수 있다.
- 모션 끄기/시스템 모션 감소, 화면 숨김, 지도 이동·확대 시 경로 재생을 멈추고 완성된 정적 선을 남긴다. 프레임/이벤트/SVG 레이어는 범위 변경과 언마운트 때 정리한다.
- 작은 지도에서는 상하 여백과 정보창을 줄여 핀/경로를 가리지 않게 했다. 번호형 핀과 다크 지도는 앱의 기존 주황/흰색 체계를 따른다.
- 카드 탭이 pointerup에서 메뉴를 연 직후 네이티브 click이 이동한 화살표를 다시 눌러 닫히는 문제를 발견했다. 짧은 탭 판단은 유지하고 실행 시점을 네이티브 click으로 옮겨 수정했다. 키보드·드래그 구분과 3D 반응은 유지한다.

## 검증

- `npm run build`: 통과.
- `test:calendar`: Chrome/실제 Playwright WebKit에서 한국어 음성 제목 제안/수동 제목 보존, 320·390·768·1280px 및 가로 화면, 라이트/다크 대비와 메뉴 충돌, 날짜 사진/그룹 제외, 하루·역순 기간 선택/포함 범위, 시간순 목록, 카드 이동과 복귀, 실제 SVG 선/빛 애니메이션, 재생/모션 끄기, 빈 날짜, Escape/방향키 월 경계, 90개 목록 추가 로딩, 최근 프리셋/기기 저장, 캘린더 가이드를 확인했다.
- 실제 OSM 지도 타일도 시각 검수했다. API는 모의 데이터만 사용하여 운영 로그·계정·위치를 변경하지 않았다.
- `test:voice`: 음성 인식 이벤트/오류/중단/저장/5,000자 제한 회귀 통과. 실제 휴대폰 마이크 인식 서비스 성공을 자동화로 보장하지는 않는다.
- `test:oct20-browser`: 실제 터치 카드 탭 열기/접기, 세로 제스처, 대기 3D, 모션 설정, 사진 톤과 PNG 공유, 태블릿/PC 배치, 책/TMDB/가이드 회귀 통과.
