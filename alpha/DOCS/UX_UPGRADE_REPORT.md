## 제한과 다음 제안

1. ZIP은 외부 사진의 CORS·삭제·연결 문제로 파일을 받을 수 없으면 manifest에 원본 URL을 남기고 누락 건수를 알린다. 모든 사진이 포함됐다고 잘못 안내하지 않는다. 현재 사진 총 250MiB를 넘는 단일 ZIP은 메모리 보호를 위해 중단한다. 대량 기록에는 기간별 백업을 추가하는 것이 좋다.
2. 초기화는 로그 행·그룹·현재 기기 대기열을 지운다. Storage의 과거 사진 객체 물리 정리는 별도의 참조 기반 작업이 필요하다. 다른 기기의 미동기화 편집을 전역 취소하는 서버 리비전 시스템은 후속 과제다.
3. 사진 압축은 신규 로컬 선택부터 적용했다. 기존 원격 이미지와 과거 저장 사진을 일괄 재업로드하지 않았다. TMDB 포스터는 외부 링크다.
4. 카드 4종은 `card-design-concepts.html`에서 비교할 수 있다. 기본 사진은 MINI FEED, 기본 글은 DAY PAGE를 우선 후보로 추천한다. 최종 양식 구현 시 긴 한글 제목과 3가지 비율의 캡처 검증이 필요하다.
