## 추가 요청 대응 · 움직임과 화면 높이

| 요청 | 적용 및 검증 |
|---|---|
| 정적인 그라데이션을 움직이는 배경으로 | 서로 다른 속도로 이동·회전하는 두 레이어로 변경. 실제 시간 경과에 따라 transform이 바뀌는 것을 검사. |
| “무슨 일상을 로그할까요?”에 잔잔한 파도 | 글자마다 위상을 달리한 약 1.5px 수직 움직임. 입력하면 즉시 사라짐. |
| 입력 박스에서 첨부·저장 버튼 분리 | 제목·사진·본문만 배경 박스 안에 배치. 사진 / 장소 / 세부 설정 / 로그 저장은 박스 밖에 유지. |
| 사진이 들어가면서 본문이 스르륵 내려오기 | 사진 높이를 0에서 목표 높이까지 720ms에 걸쳐 펼침. 같은 본문 입력칸이 자연스럽게 이동하며 충분한 입력 높이 유지. |
| 로그북 끝에서 살짝 튕기는 느낌 | 세로 드래그·휠이 상하단에 도달하면 최대 44px의 저항과 복원 탄성. 가로 삭제 제스처는 유지. 검색 툴바는 움직이지 않음. |
| 스튜디오 카드를 좌우 관성으로 전환 | 이전/현재 카드를 좌우로 이동하고 작은 overshoot 후 약 680ms에 정착. 화살표 방향을 반영하고 연속 변경도 처리. |
| Google 결제 연결 후 재검증 | 실제 Google Places 검색 성공. 검색 결과 선택 → 좌표 포함 로그 저장 → 실제 OSM 핀까지 확인. |
| 기본 프리셋을 즉시 적용하고 맨 앞으로 | 지정 버튼 한 번으로 현재 프리셋을 저장하고 기본값 변경. 주황 기본 칩을 첫 번째로 배치하고 레일도 처음으로 이동. 재접속 후 유지. |
| 상단 메뉴 크기·굵기 강화 | 데스크톱 17px, 모바일 15px, 좁은 화면 14px / 800 weight. 세 메뉴가 한 줄에 들어오는지 확인. |
| PC·태블릿에서도 입력창이 화면 높이를 채우게 | 모바일 전용 높이 연동을 전체 폭으로 확장. 입력 면을 늘리고 첨부·저장을 화면 하단에 배치. 320×568부터 1366×768까지 검증. |
| OS 동작 줄이기로 애니메이션이 보이지 않던 현상 | OS 설정은 브라우저들에 공통이지만 앱의 켜기 선택은 브라우저별 저장값이어서 새 브라우저에서 다시 멈추던 문제를 수정. 테스트 버전의 최초 기본값을 켜기로 변경. 명시적으로 선택한 기기 설정 / 끄기는 재접속 후 유지. 배경은 7초/10초 주기로, 문구는 ±3.5px·3.4초 주기의 잔물결로 조정. |
| 카드의 날짜·이름·양식·비율·컬러테마를 한 줄로 | 11개 카드 공통 하단을 한 줄로 통합. 긴 이름과 테마명은 말줄임으로 처리하고 원래 값은 보존. |
| 컬러테마 접두사 | 카드 하단 테마명 앞에 `THEME:` 표시. |
| 세부 → 세부사항, 장식 문구 숨기기 | 세부사항의 장식 문구 옵션으로 브랜드명·슬로건·분류 장식을 표시/숨김. 프리셋 저장과 카드별 스타일 스냅샷에 함께 보관. |

## 외부 서비스 연결

OSM 지도는 Google 웹 지도 키 없이 동작합니다. 전달받은 Google 키를 테스트 폴더의 비공개 .env.local에 적용했습니다. 키의 API 허용 목록에 맞춰 기존 Places API의 Find Place를 사용하며, 브라우저 코드에는 키를 넣지 않습니다. 결제 연결 후 `리움미술관` 실제 검색에서 Google 결과와 위도·경도를 받았고, 해당 결과로 로그를 저장한 뒤 지도 핀까지 확인했습니다. Google 연결 실패 시에는 기존 대체 검색을 사용합니다.

## 검증 방법

- TypeScript 및 프로덕션 빌드.
- 저장소·API: 오프라인 저장/재시작/재연결, 중복 방지, 편집 날짜 유지, 삭제 복원, 소유 기기, 그룹 참조, 좌표 검증, 프리셋 제한·보관 실패.
- UI 통합: 작성 → 분류 → 로그북 → 카드 → 편집/적용/저장/공유, 그룹 생성·수정·삭제, 스튜디오 저장 전후 격리, 오프라인 재실행.
- 320×568부터 데스크톱까지 화면 크기 확인, 11가지 카드 × 3비율에서 인쇄 정보 잘림 확인.
- 실제 OSM 타일 로딩·출처·다크 처리·핀·검색·줌·재진입 확인.
- PWA 서비스 워커로 완전 오프라인 문서 재실행·저장·재연결 확인. 지도 타일의 오프라인 일괄 저장은 하지 않음.

테스트는 데스크톱 Chrome의 화면 크기 에뮬레이션입니다. 실제 iOS의 소프트 키보드·시스템 공유 시트·햅틱 촉감은 실기기에서 최종 확인할 수 있습니다.
Google 키 적용 검증: 서버 전용 저장, 실제 기존 Places API 연결 성공, 위치 필드 최소 요청. 실제 키 값은 문서에 포함하지 않음.
