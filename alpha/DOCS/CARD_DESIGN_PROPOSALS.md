# 15종 출시를 위한 카드 디자인 제안

현재 구현된 엔진은 11종이다. 아래 4종은 추가 구현 전 비교 시안이며 기능 완료 목록과 구분한다. `card-design-concepts.html`에서 네 디자인을 비교할 수 있다.

| 추가 양식 | 역할 | 디자인 기준 | 권장 우선순위 |
|---|---|---|---|
| DOODLE NOTE | 글 위주 일상, 선택적 사진 | 종이색·손으로 그린 모서리·살짝 흐트러진 기준선. 본문은 또렷한 한글 활자 | 2차 |
| MINI FEED | 사진 한 장과 짧은 문장 | 익숙한 사진 피드 비율, 읽기 쉬운 제목·본문. 반응 수치나 SNS 로고 없음 | 1차, 기본 사진 후보 |
| POCKET PHOTO | 좋아하는 순간 수집 | 사진 중심의 포토카드, 얇은 테두리·작은 서명·부드러운 색상 | 2차 |
| DAY PAGE | 사진 없는 개인 일기 | 큰 날짜와 제목, 본문은 5–7행. 기존 도서관 카드·포스터와 다른 날짜 중심 계층 | 1차, 기본 글 후보 |

새 양식도 장식 문구·서명·번호·위치 표시를 각각 제어하고 기존 카드 스냅샷을 유지해야 한다. 그룹 전용 LIST와 일반 카드의 호환 규칙도 적용한다. 전체 모양을 15종으로 늘리는 것보다 기본 사진·글 카드 각각 하나의 완성도를 먼저 검증하는 순서가 좋다.

## 사용한 스킬과 판단

- 공식 소스: https://github.com/nextlevelbuilder/ui-ux-pro-max-skill
- 설치 위치: `C:/Users/User/.codex/skills/ui-ux-pro-max`
- 설치 리비전: `56ea9cf174ed86786187daa9de0e6247cb0747e4`
- `skill-installer`로 설치한 후 로컬 검색 실행 확인. 새 운영 의존성이나 유료 서비스는 아니다.
- `editorial scrapbook typography --domain style` 검색의 Editorial Grid / Magazine 및 Exaggerated Minimalism 결과는 제목 위계·제한된 강조색에 참고했다.
- `onboarding progressive disclosure --domain ux`의 User Freedom 결과는 건너뛰기·이전·다음 안내에 적용했다.
- Next.js 검색의 이미지 최적화 권고는 일반 페이지에 유용하지만, 카드 내보내기에서는 동일 원본을 직접 압축·캡처하는 현재 구조를 유지한다. 스킬의 일반 권고보다 사용자 목표와 실제 렌더링 검증을 우선한다.
- 종합 디자인 시스템 검색은 `personal diary editorial` → `editorial photography cards`로 한 차례 좁혀도 스크롤형 소개 페이지 패턴을 추천했다. L2 카드에 맞는 종합 추천은 확인하지 못해 저장·적용하지 않았다. 이번 카드 시안 자체는 기존 L2 레퍼런스와 개별 스타일 검색을 바탕으로 직접 설계했다.
- 다른 스킬을 무조건 추가할 필요는 없다. 이 프로젝트에서는 원본 레퍼런스, 실제 카드 렌더러와 320px·태블릿·PC 화면 검증이 추가 스킬 수보다 중요하다.
