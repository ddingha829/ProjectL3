## 실제 구현과 타이포그래피

- `src/components/AdditionalCardLayouts.tsx` / `.module.css`: 새 9종을 기존 11종과 분리한 렌더러. CSS는 화면 폭 대신 카드의 420px 논리 좌표와 비율을 기준으로 동작해 프리뷰와 내보내기가 일치한다.
- 한글 제목은 기존 카드와 같은 Pretendard Variable 900, 일반 비율에서 36–46px(낙서 스토리 48px), 짧은 본문은 17–24px를 사용한다. 18자·32자 경계에서 제목을 단계적으로 줄이고, 정사각형에서는 별도 위계를 적용한다. 영문 소제목은 Inter, 작은 번호는 JetBrains Mono다.
- 날짜·작성자·양식·비율·`THEME:`은 공통 한 줄 푸터를 재사용한다. 긴 작성자·테마는 말줄임 처리한다. 한글 제목과 본문은 비율별 줄 수만큼 요약 표시하며 원문 데이터는 변경하지 않는다.
- PAINT BADLY는 128×76 정수 격자의 Bresenham 픽셀 경로를 인라인 SVG로 생성한다. 외부 이미지·캔버스 실행 시점·무작위 값에 의존하지 않아 이미지 저장 시에도 같은 낙서를 유지한다.
- TWO CUTS는 같은 업로드 사진 한 장을 두 창에서 보여주며 두 번째 창은 1.45배로 확대한다. 기존 사진 위치 조정도 연결한다.
- 새 설치의 초기 라이브러리는 기존 6개 + 새 9개 = 15개다. 기존 사용자의 저장된 프리셋·기본값·카드 스냅샷은 덮어쓰거나 자동으로 다시 채우지 않는다. 기존 사용자도 스튜디오 → 디자인에서 새 9종을 선택하고 새 프리셋으로 저장할 수 있다. 저장 한도는 20개다.
- 새 기본 조합은 OAT MILK·SAGE MIST·DUSTY ROSE·LILAC PAPER·SWISS PAPER를 사용하며, 모든 디자인은 사용자가 선택한 팔레트를 그대로 따른다.

## 검증

- `npm run build`, `npm run typecheck`, 저장소/안정성 회귀 검사.
- `npm run test:card-exports`: 기존·신규 전체 20종 × 3비율 = 60개를 실제 이미지로 내보내고 JPEG, 최대 1080px, 500KiB 이하, 종횡비와 번호 숨김을 확인한다.
- `npm run test:card-designs`: 새 양식의 저장 타입 검증, 사진/텍스트/그룹 호환, 사용자 프리셋 보존, 긴 한글 제목·본문·주소·서명 × 3비율, 옵션 숨김, 320·768·1440px 화면 검사. 제목·본문과 푸터 겹침, 카드 영역 밖 넘침, 줄 중간 잘림까지 확인한다.
- `npm run test:guides-studio`: 사진용 일반 디자인 12종·텍스트용 7종·그룹용 LIST 1종으로 선택 목록을 갱신했다.
- 테스트는 로컬 격리 서버와 가상 API 응답으로 실행하며 운영 DB와 유료 API를 호출하지 않는다. Git 푸시·배포는 별도다.

## 시안 제작 당시 기록

- 첨부된 NOHEA 9칸 보드에서는 아치, 원형·비대칭, 두 컷, 넓은 가로 사진의 **배치 원리만** 참고했다. 상호·홍보 카피·사진은 가져오지 않았다.
- 새 시안은 프로젝트에 있던 가상 카페·미식·전시 사진을 사용한다. TWO CUTS도 한 파일을 두 번 크롭하며 두 장 업로드 기능을 전제하지 않는다.
- PAINT BADLY 낙서는 canvas에 직접 정수 픽셀 선으로 그렸다. 이미지 생성 API·원격 폰트·새 런타임 패키지는 추가하지 않았다. 미리보기는 `image-rendering: pixelated`로 낮은 해상도의 선을 보존한다.
- UI UX Pro Max의 `editorial asymmetric photography --domain style` 결과 중 Editorial Grid / Magazine의 비대칭 그리드·활자 위계·한 가지 강조색 기준을 참고했다. 과한 필터나 움직임은 넣지 않았다.
- 당시 변경은 시안 HTML과 문서에만 적용했다. 이후 실제 구현 상태는 문서 상단을 기준으로 한다.
