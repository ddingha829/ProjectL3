# 프리셋 관리·TMDB 내보내기·21색 팔레트

2026-10-18 후속 요청 반영. 앞서 승인한 9종 디자인(전체 20종)과 함께 배포하는 변경이다.

## 요청별 대응

| 요청 | 적용한 동작 |
|---|---|
| 프리셋 위치 드래그 | 프리셋 오른쪽 이동 손잡이를 마우스·터치로 드래그한다. 가장자리에서는 목록이 자동 스크롤한다. 놓으면 순서를 기기에 즉시 보관하고 계정에 동기화한다. 터치 취소는 원래 순서로 복구한다. 손잡이를 눌러 앞/뒤 이동 메뉴를 열거나 방향키로도 이동할 수 있다. |
| + 버튼까지 스크롤되는 문제 | + 버튼을 스크롤 영역 바깥의 독립 열로 이동했다. 목록을 끝까지 밀어도 버튼과 프리셋이 겹치지 않는다. |
| 카테고리별 기본값 | 기본 프리셋 지정 버튼에서 전체 기본·미식·영화·장소·기타를 고른다. 선택 즉시 저장되며 프리셋 저장 버튼을 따로 누르지 않아도 된다. 카테고리 지정이 없으면 전체 기본을 사용한다. 카테고리 기본값 해제도 제공한다. |
| TMDB 카드 저장·공유 오류 | 화면 표시용으로 먼저 저장된 이미지 캐시에 CORS 헤더가 없는 문제를 실제 TMDB CDN에서 재현했다. `html-to-image` 리소스 요청에 `fetchRequestInit: { cache: 'reload' }`를 적용해 CORS 응답을 새로 읽는다. 이미지 캐시 키는 쿼리도 포함한다. 포스터 원본 URL은 그대로 보존하며 이미지 프록시·서버 업로드는 추가하지 않았다. |
| 팔레트 11 → 21개 | 아래 10개 조합을 추가했다. 기존 사용자의 색상 변경·삭제 표시와 저장 카드 스냅샷은 유지한다. 기존 계정에서도 새 기본 팔레트를 선택할 수 있다. |
| 팔레트 한 줄 3개 | 휴대폰·태블릿·PC 모두 색상 선택창을 3열로 표시한다. 디자인 양식 선택창의 열 수는 그대로다. 이름은 최대 두 줄, 삭제 버튼은 별도 공간을 확보한다. |

## 기본값과 순서의 규칙

- `PresetSlot.defaultFor`에 카테고리를 보관한다. 기존 Supabase `preset_slots` JSON에 함께 저장하므로 DB 컬럼 추가 없이 다른 기기에도 동기화한다. API와 로컬 정규화에서 허용된 카테고리만 남기고 중복 지정은 하나로 정리한다.
- 한 프리셋을 여러 카테고리의 기본값으로 지정할 수 있다. 같은 카테고리를 다른 프리셋에 지정하면 기존 지정만 옮긴다. 단순 디자인 편집·저장은 카테고리 기본값을 바꾸지 않는다. 새 프리셋 복사도 기존 프리셋의 기본값 역할을 가져오지 않는다.
- 새 로그를 저장할 때 선택한 카테고리의 프리셋을 사용한다. 사진이 없는 경우 기존 호환 규칙에 따라 텍스트 양식으로 표시한다. 기존 로그는 자신의 `cardAppearance`를 유지한다. 그룹은 계속 LIST 전용이다.
- 기본값 지정 직후에는 해당 프리셋을 앞으로 이동한다. 이후 직접 드래그한 순서가 우선한다. 전체 기본 프리셋도 수동으로 이동할 수 있다. 기본값은 주황색과 범위 이름으로 구분한다.
- 순서 변경은 등록된 프리셋을 지우거나 복제하지 않는다. 실패한 기기 저장을 성공으로 표시하지 않으며, 기존 계정별 오프라인 동기화 절차를 재사용한다.
