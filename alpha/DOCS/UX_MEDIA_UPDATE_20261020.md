# 로그북 · 카드 편집 · 작품 연결 업데이트 (2026-10-20)

## 요청별 반영

1. **검색 메뉴:** 상단 간격을 `max(24px, safe-area-inset-top)`으로 늘렸다. Safari visualViewport의 offsetTop 변화도 반영한다. 배경 불투명도는 83% → 64%로 줄이고 blur를 유지한다. 로그북 조상의 overflow도 명시해 검색 메뉴가 잘리지 않도록 했다.
2. **시스템 기본 프리셋 / 사진 보정:** 새 사용자와 기본값이 없는 프로필은 `02 / INSTA`를 사용한다. 기존 사용자가 지정한 기본값과 기존 로그 스냅샷은 덮어쓰지 않는다. 카드 상세와 스튜디오 공용 세부사항에 채도(0~200%), 명도(-50~50), 밝기(50~150%) 및 초기화를 추가했다. 수치는 PresetSlot JSON에 저장하고 서버에서 정규화한다. 명도는 흰색/검은색 방향의 톤 조절, 밝기는 노출 배율 조절로 분리했다. 공유 PNG에도 적용된다.
3. **TMDB 소개:** 검색 목록 조회는 AI를 호출하지 않는다. 작품을 선택할 때만 `/api/media/summary`가 한 문장, 필요 시 두 문장으로 요약한다. 출력은 최대 160자로 제한하고 기존 20회/일 한도를 공유한다. 성공한 공개 소개 요약은 프로세스 메모리에 최대 200개, 24시간 캐시한다. 실패·한도 초과 시 원문을 최대 두 문장으로 줄인다. 참고 메모 교체 시 기존 작품 참고 블록을 정리해 중복을 줄인다.
4. **모바일 카드 상세:** 큰 카드가 먼저 보인다. 위로 밀기 / 아래 안내 버튼 / 키보드로 편집 메뉴를 연다. 다시 접어도 현재 디자인 초안은 유지된다. 내용 수정·카드 저장·공유는 편집 메뉴 안에 있다.
5. **가이드:** 영화·드라마·책 표지 선택, 사진 톤 보정, 편집 메뉴 열기, 넓은 화면 배치, 3D 효과 설명을 반영했다. 가이드가 숨겨진 편집 항목을 안내할 때 해당 메뉴를 먼저 연다. 기존 사용자를 강제로 재온보딩하지 않는다.
6. **책 검색:** 사진 추가 모달의 ‘책 검색’으로 카카오 도서 API를 호출한다. 제목/저자/ISBN 검색, 표지, 저자·출판사·ISBN 메타데이터, 짧은 참고 소개를 연결한다. 분류는 기존 ‘기타’를 사용한다. 표지 없는 책도 텍스트로 기록 가능하다. 책 정보는 별도 `media` JSON에 보관하며 장소 데이터와 섞지 않는다. 좌표를 직접 연결하지 않은 책은 장소 자동 연결 대상에서 제외한다.
7. **3D 느낌:** 카드 상세·스튜디오 미리보기에 마우스 위치에 따른 작은 기울기, 탭 시 기울었다 복귀하는 반응, 은은한 하이라이트/그림자를 추가했다. 뒷면·뒤집기는 구현하지 않는다. 모션 끄기/감소 설정을 따르고, 효과 요소를 캡처 노드 밖에 두어 내보내는 이미지는 평면 PNG로 유지한다.
8. **PC·태블릿 카드 상세:** 760px 이상에서는 왼쪽 카드 / 오른쪽 편집 메뉴로 배치하고 편집 메뉴를 바로 표시한다. 공유된 스튜디오 CSS가 카드 상세 안에 암묵적 열을 만드는 문제도 별도 grid 배치로 차단했다.

## 서버 설정과 실연결

- `KAKAO_REST_API_KEY`: 로컬 `.env.local`과 Vercel project-l3 Production·Preview에 서버 전용 Secret으로 등록했다. 키 값은 문서·Git에 포함하지 않는다.
- 카카오 실제 검색: ‘채식주의자’ 검색에서 결과 18개, 한강 저자 정보, ISBN을 확인했다. 첫 표지를 같은 출처 프록시로 가져와 HTTP 200 / image/jpeg / 10,651bytes를 확인했다.
- `/api/media/image`는 `search1~4.kakaocdn.net`의 이미지만 허용한다. 리디렉션을 금지하고 이미지 MIME·3MiB 크기 제한·타임아웃을 적용한다. 브라우저 CORS 문제 없이 카드로 내보내기 위한 프록시이며 Supabase Storage에 표지를 복제하지 않는다.
- Gemini 실제 연결: 기존 로컬 설정 키와 사용자가 후속 메시지로 제공한 키는 서로 다르다. 두 키 모두 별도로 확인했으며 모델 목록은 조회되지만 생성 요청은 HTTP 402 / RESOURCE_EXHAUSTED / prepayment credits depleted를 반환했다. 후속 키로 로컬·Vercel 설정을 교체하지 않았다. Vercel Secret은 읽어 되돌릴 수 없어 저장된 값의 동일 여부는 확인하지 못했다. 현재는 **실제 AI 생성이 가능한 상태로 판정하지 않는다.** 대체 요약은 정상 동작한다. 선결제 잔액은 사용자가 관리해야 한다. 402에서는 다른 모델 재시도를 중단해 불필요한 실패 요청을 줄였다. 실연결 검사는 별도 로컬 파일 사용량 저장소를 사용했고 Supabase 사용자 데이터는 변경하지 않았다.
- Supabase의 새 테이블/컬럼은 필요 없다. 기존 JSON 필드에 사진 보정과 작품 정보를 저장한다. schema.sql의 신규 프로필 기본 ID는 02로 맞췄으며 운영의 기존 기본값을 일괄 수정하는 SQL은 실행하지 않았다.

## 검증

- `npm run build`, `test:repository`: 통과. 저장소 검사는 책 메타데이터·사진 보정값의 생성/내용 수정/디스크 저장도 포함한다.
- `test:oct20-api`: 카카오 요청/응답 매핑, 키 누락, 이미지 프록시 허용 목록, AI 선택 시 호출/캐시/한도/두 문장 대체 처리, INSTA 초기 기본값, 보정값 정규화. 외부 요청은 모의 처리.
- `test:oct20-browser`: Chrome 및 실제 Playwright WebKit(Windows)에서 검색 메뉴 스크롤, 모바일 편집 열기, Chrome CDP 실제 터치, 3D 탭/모션 끄기, 보정 저장·공유 픽셀, 태블릿/PC 내부 메뉴 정렬, 스튜디오 원본 독립성, 책·TMDB 선택/저장/공유, 가이드 검증. 물리 아이폰 검사는 아니다.
- 기존 가이드/스튜디오, 사진 첨부·스와이프·백업·초기화, 카드 디자인/비율별 투명 PNG 내보내기 회귀 검사를 수행했다. 출력 폴더는 작업 환경의 `outputs/oct20/`이다.
