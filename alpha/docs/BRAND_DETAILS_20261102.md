# Ticgle interface details

- Shared three-dot motif and single-action empty states for the feed, map and
  first-work collection tray. Search-empty state keeps the reset action. Map
  invitation only appears when no located record exists; markers are unchanged.
- Collection title retains the personal/group name. Current-board count and 16
  dots are grouped below it; bottom controls retain paging/editing. Existing
  incremental encouragement, completion glow and placement logic are preserved.
- Group scope has an initial/speck emblem; dropdown options show actual member
  initials and count using already-loaded profiles. Full names stay available as
  avatar tooltips. No new requests or invented member data.
- Search anchors the toolbar. Applied query/category/sort/photo conditions have
  independent native reset buttons; chips do not appear without conditions.
  Existing sticky observer, input node and popover keyboard behavior remain.
- Confirmed save uses a short three-dot gathering caption above dock space.
  It never blocks pointers or renders a duplicate full card. Confirmation still
  waits for the original persistence state. Reduced motion removes dot movement.

Validation: typecheck, build, surface interaction (10), sticky toolbar (14) and
static component rendering checks passed. The rendering checks cover filter
conditions, progress values, native actions and group identity. Live browser and
physical-phone visual checks remain unavailable with local browser use disabled.
No database migrations, production fixtures or server polling are added.
