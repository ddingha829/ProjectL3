# 저장 실패와 복구 안내 — 2026-10-30

- 운영 DB의 반복 오류는 `l2u_apply` 공감/담아두기 취소 분기의 `kind` 컬럼과 PL/pgSQL 지역 변수 충돌(42702). 이 작업이 미반영 큐에 남으면 함께 전송하는 댓글도 롤백된다. migration 008에서 해당 DELETE의 컬럼만 테이블 별칭으로 한정한다. 함수 본문과 권한을 보존하고 예상하지 못한 본문이면 중단하며 재실행 가능하다. 운영 SQL 적용 성공 확인.
- 기존 오류 안내는 실패 상태에 닫기 버튼이 없었고, 카드 모달이 배경 앱을 inert 처리하여 안내의 버튼까지 비활성화했다. 활성 모달 내부로 안내를 포털 렌더링하고 모달 스택 변경 시 위치를 갱신한다. 기존 모달 격리는 유지한다.
- 닫기 버튼은 항상 제공. 닫으면 미반영 작업을 삭제하지 않고 작은 ‘미반영 변경’ 버튼으로 축소한다. 다시 열어 재시도/백업 후 복구 가능. 긴 복구 버튼을 두 개의 44px 이상 버튼으로 정리한다. SQL/네트워크/권한 오류 안내도 구분한다.

검증: DB/RLS 52개 통과. 생성한 일회용 계정에서 운영 API로 공감/담아두기 취소와 댓글을 한 트랜잭션으로 저장하고 동일 작업 ID 재전송 시 댓글 1개 유지 확인. 해당 계정의 테스트 기록과 계정만 검증 후 제거. 실제 사용자 데이터 변경 없음. 브라우저 320×568 및 393×793에서 닫기/재열기/재시도, 모달 열기·닫기 후 상호작용, 가로 넘침 없음 확인. TypeScript와 production build 통과. 로컬 검증 페이지는 빌드 전 제거. 실기기 검증은 미실시.
