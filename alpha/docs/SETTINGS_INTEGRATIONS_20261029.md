# 설정 연동 정보 분리 및 설치 iPhone 상단 여유

- 설정에서 닉네임 다음에 알림을 표시한다. 기존 연동 상태·AI 사용량·정보 출처는 맨 아래 `서비스 연동` 메뉴의 별도 시트로 이동한다.
- 연동 상태 컴포넌트는 메뉴를 열 때만 마운트한다. 설정 첫 진입에는 불필요한 연동 상태 요청을 하지 않는다.
- 하위 시트는 기존 AccessibleDialog의 스크롤·포커스 격리를 사용한다. 돌아가면 서비스 연동 버튼으로 포커스를 복구하고 설정을 닫으면 하위 시트 상태도 초기화한다.
- 393×793 및 320×568 브라우저에서 메뉴 순서, 하위 시트, 정보 출처 펼침, 복귀, 닫기·재진입 scrollTop 0, 가로 넘침 없음, 라이트·다크를 확인했다.
- TypeScript, 프로덕션 빌드, viewport 회귀 20개, 피드 툴바 회귀 14개 통과.

## 상단 잔여 흐림 보고

사용자가 alpha-68978f1 설치 iPhone에서 로고와 헤더 상단의 미세한 흐림을 보고했다. 보고된 레이아웃은 393×793, screen.height 852, visualTop 0이며 리모콘 위치는 정상이다.

앱 헤더와 chrome의 filter/backdrop-filter/mask는 이미 none이고 헤더 배경은 불투명하다. 따라서 CSS 블러 제거를 반복하지 않는다. 설치 iOS 세로 화면에서만 기존 상단 추가 여유를 12px에서 18px로 늘려 글리프를 6px 아래로 피한다. 일반 브라우저와 가로 화면, 문서 높이, 리모콘 하단 계산은 유지한다.

이 조치는 시스템 합성 효과를 해제한 것이 아니다. WebKit의 설치 앱 상단 영역 보고와 사용자 캡처로부터 시스템 효과가 겹쳤을 가능성을 추정한 완화 조치다. 실제 아이폰의 개선 여부는 재실행 후 확인이 필요하다. 데스크톱 검증으로 실기기 블러 해결을 주장하지 않는다.
