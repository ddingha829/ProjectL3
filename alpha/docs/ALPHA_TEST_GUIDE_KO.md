# 지인 알파테스트 안내

주소: https://project-l3-nine.vercel.app/

이메일과 비밀번호로 가입하면 바로 사용할 수 있어요. 실제 저장·모임 테스트는 ‘먼저 둘러보기’ 대신 가입한 계정으로 진행해주세요. 현재 알파 버전이며 이메일 인증은 진행하지 않아요. 테스트 종료 후 데이터는 정식 서비스에서 사용할 수 있는 형태로 백업한 뒤 삭제할 예정이에요.

## 10분 사용해 보기

1. 이메일로 가입하고 앱을 껐다 다시 열어 로그인 상태를 확인해요.
2. 사진을 찍거나 앨범에서 골라 로그를 등록해요. 위치·날씨·별점도 한 번 확인해요.
3. 영화나 책을 찾아 작품 로그를 등록해요. 글만 쓰기도 한 번 사용해요.
4. 피드에서 카드를 열고 앞뒤로 뒤집은 뒤, 이미지로 저장하거나 공유해요.
5. 지도 가운데에서 이동·확대·축소해요. 양옆 가장자리를 안쪽으로 밀면 메뉴가 바뀌어요. 타일·스튜디오도 좌우로 넘겨보고, 캘린더의 날짜와 지도를 확인해요.
6. 타일 탭에서 원하는 칸에 놓고, 옮기거나 다음 판으로 넘겨요.
7. 스튜디오에서 프리셋을 꾸미고 저장한 뒤 다시 열어봐요.
8. 한 사람이 모임을 만들고 6자리 코드를 공유해요. 다른 사람이 참여해서 공유된 로그를 보고 댓글을 남겨요.
9. 공유하지 않은 개인 로그가 다른 계정에 보이지 않는지 확인해요.
10. 가능하면 홈 화면에 설치해서 카메라·GPS·공유와 다시 실행하기를 확인해요.

## 불편하거나 안 되는 부분 보내기

설정 → 알파테스트 · 문제 알리기 → 문제 알리기에서 내용을 적고 **보고서 복사**를 눌러 초대받은 대화방에 보내주세요. 가입·로그인이 안 되면 로그인 화면 아래의 **문제 알리기**를 이용할 수 있어요. 보고서는 자동 전송되지 않으며 파일 저장도 지원해요.

버전·브라우저·화면 크기·설치 앱 여부가 자동으로 포함돼요. 계정 정보·로그·위치는 자동 첨부하지 않아요. 아래 내용과 캡처/녹화가 있으면 문제를 찾기 쉬워요.

- 기기: 아이폰/안드로이드 모델
- 실행 방법: Safari/Chrome/홈 화면 설치 앱
- 누른 순서:
- 기대한 결과 / 실제 결과:
- 화면 캡처 또는 녹화:

비밀번호는 보내지 않아도 됩니다. 카메라 배율·GPS·공유 시트는 기기별 차이가 있어 이 부분을 특히 확인해주세요.
