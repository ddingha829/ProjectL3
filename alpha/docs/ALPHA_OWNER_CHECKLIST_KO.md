# 알파테스트 시작하기

공유 주소: https://project-l3-nine.vercel.app/

## 사용자님이 할 일

1. **1차 테스터 3~5명 선정**: iPhone과 Android가 각각 한 명 이상이면 좋아요. 3일 정도 평소처럼 써보는 작은 그룹부터 시작하는 것을 추천해요.
2. **실제 계정으로 모임 하나 만들기**: 상단 마이로그 드롭다운 → 코드로 참여 · 모임 만들기. 모임을 만든 뒤 관리 화면에서 6자리 코드를 복사해요.
3. **주소·코드·초대 문구 전달**: 설정 → 알파테스트 · 문제 알리기 → 테스트 안내 → 초대 문구 복사. 초대 코드는 별도로 붙여 보내주세요. 예시 계정에서는 실제 모임 테스트가 되지 않아요.
4. **실기기 확인 요청**: 각자 촬영/앨범, GPS/날씨, 공유, 앱 재실행 후 기록 유지, 메뉴 스와이프를 확인해요. 모임원끼리 공유된 기록과 공유하지 않은 개인 기록을 구분해 확인해요.
5. **문제 보고서 모으기**: 설정 또는 로그인 화면의 문제 알리기에서 보고서를 복사해 초대받은 대화방으로 보내도록 안내해요. 모인 보고서와 캡처/녹화를 이 채팅에 전달하면 수정 작업을 이어갈 수 있어요. 비밀번호는 받지 마세요.

## 이미 준비된 것

- 공개 라이브 주소, 이메일/비밀번호 즉시 가입, 6자리 초대 코드와 모임 공유.
- 새 카드/지도/타일/스튜디오, 개인 ZIP 백업, 저장 실패 시 재시도와 임시 백업.
- 테스트 안내, 초대 문구, 버전/기기 정보가 들어간 보고서 복사·텍스트 파일 저장.
- 로그인 전에도 열 수 있는 문제 보고 화면. 별도 가입이나 외부 설문 서비스 설정은 필요 없어요.
- 보고서에는 계정·토큰·로그·좌표·초대 URL이 자동으로 들어가지 않아요. 사용자가 적은 내용은 그대로 포함되며 자동 전송되지 않아요.

## 1차 종료 후 판단

- 가입/로그인 불가, 기록 누락, 개인 기록 노출, 다른 사람 기록 수정 같은 문제는 먼저 수정하고 다시 확인해요.
- 핵심 동작에 문제가 없으면 참여자를 늘리고 디자인/문구 의견을 모아요.
- 테스트 데이터 삭제는 지금 실행하지 않아요. 종료 시점과 전체 백업 검증 후 별도 진행해요.
