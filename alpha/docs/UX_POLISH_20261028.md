- 놓을 타일이 0이면 수량과 제목을 숨기고 짧은 안내로 대체한다. 비어 있거나 채워져도 트레이 높이는 유지한다. 작은 화면의 트레이 포스터 비율/가로 스크롤을 보정한다.
- 배치 1~15장에는 단계별 격려와 점진적인 빛 강도, 4/8/12장에는 줄·절반 문구, 16장에는 특별 발광과 완성 문구를 제공한다. 초기 진입 때 기존 완성판을 반복 축하하지 않는다. reduced-motion에서는 움직임을 제거한다.
- 피드·상세·스튜디오·PNG 세로 카드는 사용자 확인한 10:16으로 통일한다. 정사각형은 유지한다. 기존 9:16 데이터는 읽을 때 비파괴적으로 10:16으로 정규화한다. 삽입 사진 영역 치수는 기존 피드 기준을 유지한다.

- ticgle.kr이 실제로 www.ticgle.kr로 이동하는 것을 확인했다. canonical/OG/Twitter 메타와 1200×630 브랜드 미리보기 PNG를 제공한다.
