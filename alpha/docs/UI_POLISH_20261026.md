# 피드·검색·촬영 UI 조정

- 피드의 세로 카드 미리보기만 10:16(논리 420×672)으로 표시한다. 상세 뷰어·스튜디오·내보내기의 기존 비율과 1:1 카드는 유지한다.
- 티켓·폴라로이드의 사진 영역은 기존 420×747 카드의 높이를 유지하고, 하단 여백과 정보 간격을 정리했다.
- 모바일 피드는 기존 2열의 가로 폭을 유지한다. 화면 높이에 따라 그리드 폭을 줄이던 규칙은 사용자 피드백에 따라 제거했다. 높이만 10:16으로 줄이고, 짧은 화면에서는 세로 스크롤을 허용한다.
- 검색을 헤더에서 피드 도구 모음의 왼쪽으로 이동했다. 검색창이 펼쳐지면 도구는 글자 없이 오른쪽 아이콘으로 모인다. 다른 도구/카드/영역을 누르거나 Escape를 누르면 검색어를 유지하고 접힌다.
- 검색의 펼침 상태·키보드 포커스·검색어 적용 표시를 유지하며, 모션 감소 설정에서는 전환 애니메이션을 끈다. 도구 버튼의 터치 영역은 44px를 유지한다.
- 촬영 화면의 뒤로가기는 왼쪽 16px, 카메라 설정은 68px에 각각 44px 크기로 배치한다. 설정 패널도 버튼 아래로 정렬한다.
- 초기 가이드의 검색 위치와 동작 설명도 갱신했다.

## 확인

- TypeScript 및 Next.js 프로덕션 빌드.
- 예시 계정에서 네 번째 로그를 UI로 작성한 후 390×699, 320×568 모바일 레이아웃 확인. 네 번째 카드 하단이 리모컨 상단보다 위에 있고 가로 넘침 없음.
- 검색 펼침, 검색어 입력/유지/초기화, 다른 도구로 전환, Escape로 접기 확인.
- 티켓·폴라로이드의 사진 높이는 논리 해상도에서 기존과 1px 미만 차이로 유지.
- 카메라 하드웨어를 사용할 수 없는 테스트 브라우저에서는 설정 버튼이 나타나는 실제 카메라 미리보기의 검증은 제한된다. 기기에서 두 버튼 간격을 최종 확인한다.

기존 개인용 Production은 교체하지 않고 codex/unified-vercel Preview에만 반영한다.

추가 확인: 동일한 화면 너비에서는 화면 높이가 달라도 카드 너비가 유지되어야 한다. 390px 폭 기준 기존 약 171px의 카드 너비를 사용하며, 10:16 미리보기 높이는 약 274px다.
