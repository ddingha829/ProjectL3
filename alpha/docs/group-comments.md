# 모임별 댓글

카드 원본·이미지·좋아요는 기존처럼 공유하고 댓글과 대댓글은 `groupId`로 분리한다. `null`은 카드 주인의 개인 댓글, UUID는 해당 모임 댓글이다. 피드의 댓글 수와 상세 스레드는 현재 스코프만 필터링하며, 렌더링을 위해 원본 상태를 덮어쓰지 않는다. 카드 편집 저장도 다른 모임의 댓글 배열을 보존한다.

마이그레이션 16은 `l2u_comments.group_id`와 조회 인덱스를 추가한다. RLS와 전체 snapshot 모두 댓글 소속 모임의 멤버십 및 현재 카드 공유를 확인한다. 개인 댓글은 카드 주인만 읽고 작성한다. 대댓글은 같은 카드·같은 모임의 부모만 참조할 수 있다. 기존 저장 RPC는 groupId를 받아 검증하며, 이전 클라이언트는 모임을 하나로 확정할 수 있는 경우만 호환한다. 여러 모임 중 소속을 알 수 없으면 다시 열어 작성하도록 안내한다.

기존 댓글은 삭제하지 않는다. 공유 모임이 정확히 하나인 카드의 댓글은 그 모임에 연결하고, 소속을 알 수 없는 댓글은 개인 보관한다. 같은 마이그레이션을 다시 실행해도 새 개인 댓글을 모임으로 옮기지 않는다. 운영 적용 전후 기존 ID와 대댓글 부모를 읽기 전용으로 비교한다.

댓글 푸시는 해당 모임의 작성자·카드 주인 멤버십 및 공유 상태를 발송 때 다시 확인한다. 알림을 누르면 정확히 그 모임의 카드가 열린다. 알림 잠금 화면에는 댓글 본문을 복사하지 않는다. 새 글/좋아요/예약 알림 정책은 유지한다.

검증: `npm run test:comments`, `npm run test:db`, `npm run test:notifications`, `npm test`, `npm run build`. 실제 계정에 테스트 댓글을 삽입하지 않고 격리된 Postgres에서 두 모임·공유 원본·개인 댓글·대댓글·재실행과 예전 데이터 보존을 확인한다.
