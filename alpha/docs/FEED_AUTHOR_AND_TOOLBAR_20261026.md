# 작성자 표시와 상단 메뉴 제안

## 실제 적용

- 피드의 작성자 배지를 왼쪽 아래에서 오른쪽 아래로 옮겼다. 기존 가로 폭·10:16 미리보기·배지 스타일을 유지한다.
- EditorialFace의 앞면 티켓·폴라로이드와 뒷면에 들어가던 오른쪽 아래 @작성자 서명을 렌더링에서 제거했다. 상세 뷰어·내보내기에도 동일하게 반영된다.
- 책 작품의 AUTHOR 메타, 여권 레이아웃의 별도 메타 및 실제 로그 소유권 데이터는 이 변경 범위에 포함하지 않는다.

## 제안만 준비

비교 주소: /design-review/feed-toolbar/

- A안 추천: 검색·필터·더보기 3개로 정리. 카테고리·정렬·사진 유무는 필터, 보기모드·보관함은 더보기로 묶는다.
- B안: 카테고리를 바로 바꾸는 동작을 남기고, 검색·필터·더보기는 오른쪽에 모은다.
- 실제 피드 메뉴는 바꾸지 않았다. 비교 화면에서 검색, 분류 선택, 더보기 구성을 살펴볼 수 있다.
- UI/UX 스킬 검색 2회에서는 이 메뉴 구성에 맞는 사례를 찾지 못했다. 위 안은 현재 앱의 사용 흐름과 일반적인 기능 묶음 원칙을 기준으로 직접 구성한 제안이다.

확인: 피드 배지 오른쪽/아래 간격 8px, 실제 ec-signature 노드 0개, 상세 카드 앞뒤 747px 유지, 메뉴 시안의 필터·더보기 표시 및 TypeScript/프로덕션 빌드.
