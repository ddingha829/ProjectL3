# 지도 탐색·B안 메뉴·카드 패널 통합

## 지도

- 일반 지도 진입 시 브라우저 현재 위치를 한 번 요청하고, 성공하면 주변(줌 15)으로 이동한다. 권한/위치 확인 실패 시 기존 로그 위치 또는 기본 지도를 유지한다. GPS를 기다리는 동안 사용자가 지도를 이동/확대했다면 늦게 도착한 자동 위치가 화면을 다시 옮기지 않는다. 장소 선택용·간략 지도에서는 자동 요청하지 않는다.
- 확대 수준에 따른 표시 경계: 줌 13.5 이상 행정동, 11 이상 시·군·구, 8 이상 시·도, 8 미만 국가. 국내 상위 경계는 기존 2026-10-01 SGIS 행정동 스냅샷을 합쳐 생성한다. 단순화는 표시용이며 집계는 정확한 원래 행정동 소속을 이용해 해안선 단순화로 기록이 누락되지 않게 한다.
- 100/200/300/400% 색 강도는 유지하되 4단계에 도달하는 로그 수를 다르게 한다: 동 1/2/3/4, 시·군·구 1/4/10/20, 시·도 1/6/18/40, 국가 1/10/30/80개.
- 국내 행정구역 전환을 지원한다. 해외는 Natural Earth 국가 경계만 포함하며 상세 행정구역은 포함하지 않는다. 일반화된 경계가 없는 곳의 로그도 핀과 목록으로 접근할 수 있다.
- 동네 수준에서는 현재 화면 안의 로그를 지도 아래에 표시한다. 모바일 최대 4행 분량 안에서 스크롤하며, 지도 이동 시 목록을 갱신한다. 지도 크기 변화로 목록이 반복해서 나타났다 사라지는 현상을 막기 위해 목록 높이는 해당 범위의 전체 로그 수(최대 4행)를 기준으로 유지한다.
- 데이터는 정적 파일로 단계별 로딩하며 새 유료 API나 역지오코딩 호출을 추가하지 않는다. 출처/라이선스는 지도 정보 링크에 유지한다. 생성 도구는 `scripts/build-map-regions.py`이며 Shapely 2.x가 필요하다. 앱 실행/빌드에는 Python이 필요하지 않다.

## 실제 적용한 B안

- `전체 ▾`: 카테고리, 정렬, 사진 필터를 한 드롭다운에서 즉시 적용한다. 별도 필터 버튼은 없앤다.
- 돋보기: 기존처럼 검색창이 펼쳐지고 다른 도구는 아이콘으로 압축된다. 바깥을 누르면 검색어는 유지하고 접힌다. 떠 있는 도구 모음은 safe-area를 반영한다.
- 더보기: 카드/리스트/개인 캘린더와 보관함·담아둔 기록·컬렉션·취향 선반·로그 선택을 모은다.

## 타일과 카드

- 개인 타일 상단의 `마이로그 / 취향을 한 칸씩` 문구를 제거하고 보드를 위로 올린다. 하단 가로 팔레트의 배경 불투명도·테두리·그림자를 줄이고 안내를 짧게 정리한다. 이동/드래그/모임 보호 규칙은 유지한다.
- 카드 기본 미리보기에서도 공감·담아두기·공유·더보기(사용 가능한 경우)와 장소가 보인다. 손잡이/작성자 영역을 누르거나 위로 끌면 댓글만 추가로 펼쳐진다. 큰 화면에서도 카드 왼쪽·컴팩트 패널 오른쪽을 유지한다.
- 엽서 우표는 평점이 있으면 평점, 없으면 카테고리 심볼이다. 날짜 중복은 9개 뒷면 전체에서 정리한다. 일력·신문·도서카드는 자체 날짜 영역을 사용하고 나머지는 하단 날짜 한 곳을 사용한다.
- 초기 사용 가이드도 실제 동작에 맞춰 갱신한다.

## 검증

- 지역/확대/집계/원본 소속 보존/화면 범위 필터 검사 11개.
- 9개 뒷면 × 비율 2종 × 평점 유무의 날짜 중복 렌더 검사 36개.
- 기존 스와이프 회귀 검사 16개, TypeScript 및 프로덕션 빌드.
- 브라우저 320×568, 390×844, 1280×800에서 메뉴·댓글 패널·지도 단계·목록·라이트/다크·가로 넘침을 점검한다. 테스트 브라우저 GPS는 위치를 반환하지 않아 실패 시 대체 경로를 검증했으며, 실제 기기의 GPS 성공 경로는 추가 확인이 필요하다.
