# 우선순위 1 UI 수정 검증 — 2026-10-30

- 작은 모바일 스튜디오: 미리보기 최소 높이 확보, 설정 영역 내부 스크롤, 저장 버튼은 스크롤 밖에 유지. 확대 미리보기 제공. 카드 내용 수정의 공용 디자인 편집에도 적용.
- 작성/수정: 편집 패널 안에 뒤로가기 제공. 변경 내용이 있으면 계속 작성 또는 취소 확인. 새 티끌은 메모리에 잠시 보관하고 +로 복귀 가능. 새로고침/앱 종료 시 사라짐을 명시. 계정 전환 시 폐기.
- 입력창: 배경 불투명도와 입력/플레이스홀더 대비 강화.
- 지도: 가까운 로그 및 빈 상태 문구, 접근성 레이블을 티끌로 통일.
