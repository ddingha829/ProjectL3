# 비밀번호 확인과 설정 변경 메뉴 — 2026-10-30

- 회원가입에 비밀번호 확인 입력/보기 토글 추가. iOS 자동완성을 고려해 FormData의 제출값으로 최소 6자 및 일치를 검증. 미입력/불일치 시 요청 전 차단하고 해당 입력으로 포커스.
- 실제 계정의 설정 메뉴에 비밀번호 변경 추가. 현재 비밀번호, 새 비밀번호, 새 비밀번호 확인 입력. 현재 비밀번호로 동일 계정을 재인증한 후 Supabase updateUser로 변경.
- 저장 중 중복 제출/닫기 방지. 성공 후 입력값 삭제 및 완료 화면 제공. 창을 닫아도 상태 제거. 암호는 앱 데이터/작업 큐/로컬 저장소에 보관하지 않음.
- 계정 전환을 감지하면 업데이트를 중단. 비밀번호 변경의 USER_UPDATED 이벤트로 진행 중인 폼이 초기화되지 않게 제한적으로 처리. 기존 프로필 갱신 및 로그인 흐름은 유지.
- 테스트용 가입 정책은 사용자 확인 후 Supabase에서 저장: 유출/흔한 비밀번호 방지 끔, 최소 6자, 필수 문자 조합 없음. 5자 거부, 흔한 6자 가입/로그인 성공을 실제 API로 확인.

검증: password helper 16개, 인증 안내 14개, 인증 세션 전환 8개 통과. 로컬 UI에서 가입 확인 불일치 요청0회→일치 요청1회, 변경 오류/성공/복귀/재진입 시 초기화 확인. 실제 일회용 QA 계정에서 잘못된 현재 암호 거부→변경→이전 암호 로그인 실패→새 암호 로그인 성공 확인. 생성한 QA 계정만 ID/이메일 검증 후 제거. 기존 계정과 기록 변경 없음. TypeScript 및 production build 통과. 검증용 임시 페이지는 빌드 전 제거.
