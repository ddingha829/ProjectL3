# 피드 카드 겹침·잘림 수정

## 원인

10:16 피드 미리보기의 바깥 틀은 420×672였지만 EditorialFace가 자체 인라인 스타일로 420×747을 다시 지정했다. 실제 카드가 틀보다 길어져 다음 행과 겹치고, 작성자 배지와 카드 하단 정렬도 어긋났다. 이전 검증이 바깥 틀만 측정해 이 차이를 놓쳤다.

## 수정

- EditorialCard가 캔버스 높이를 한 번 결정해 틀·앞면·뒷면·사진 없는 단면에 동일하게 전달한다.
- ResizeObserver의 소수점 너비를 사용해 카드 내용과 틀의 축소 배율도 일치시킨다.
- 피드 미리보기 672px, 상세 뷰어 747px, 정방형 420px, 기존 내보내기 규격을 유지한다.

## 회귀 확인

- 수정 전 배포에서 모든 실제 카드 면이 틀을 초과하고, 앞 행의 면이 다음 행과 겹치는 것을 재현했다.
- 수정 후 예시 로그 4개를 사용해 320×568, 390×699, 390×844, 1280×800에서 검사했다.
- 바깥 틀뿐 아니라 화면에 보이는 실제 ec-face의 경계를 비교한다. 높이 차이 1px 이하, 면끼리 겹침 없음, 모바일 첫 4장의 실제 하단이 리모컨보다 위, 가로 넘침 없음이 통과 기준이다.
- 앞면 폴라로이드·티켓 및 사진 없는 엽서 면에서 통과했다.
- 상세 뷰어의 틀·앞뒤 면 모두 747px이며, 실제 다운로드 PNG는 1080×1920으로 확인했다.
- TypeScript와 Next.js 프로덕션 빌드 확인 후 Preview에만 배포한다.
