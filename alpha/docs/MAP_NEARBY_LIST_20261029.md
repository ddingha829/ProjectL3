# 티끌맵 하단 가까운 로그

- 확대 단계와 관계없이 지도 아래에 현재 화면 안의 로그를 중심에서 가까운 순으로 최대 2개 표시한다. 기존 지도 영역 필터와 정렬을 재사용하며, 위치가 없거나 지도 밖에 있는 로그는 제외한다.
- 목록은 모든 화면 너비에서 세로 2행 공간(98px)을 확보한다. 지도 행이 이 공간만큼 줄어들고, 결과가 0개·1개·2개로 바뀌어도 지도 높이는 유지된다. 앱 전체 높이와 도크·안전 영역 계산은 변경하지 않는다.
- 지도 초기화 전에는 조회 중 문구를 표시한다. 화면 안에 결과가 없으면 `현재 지도 안에 로그가 없어요.`를 표시한다. 이동·확대·축소 후 목록을 갱신하고 행을 누르면 기존 카드 상세를 연다.
- 타입 검사, 프로덕션 빌드, 기존 지도 영역 회귀 검사 통과. 393×793 브라우저에서 기본 줌 11의 1개·2개 목록, 상세 진입·복귀, 드래그 후 빈 상태, 지도 높이 유지(450.75px)를 확인했다. 320×568에서 가로 넘침 없음과 목록/도크 간격(10px)을 확인했다.
