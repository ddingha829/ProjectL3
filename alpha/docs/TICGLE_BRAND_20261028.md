# 티끌 브랜드 적용

## 원본

예전 ProjectL2의 실제 헤더가 참조하던 `public/logo.png`를 `public/brand/ticgle-wordmark.png`로 복사했다. 기존 디자인 가이드도 이 파일을 현행 워드마크로 지정하고 있으며, 주황색 `ticgle` 형태다.

- 크기: 919×372, RGBA.
- 원본/복사본 SHA-256 동일: `1C6DA92F9779C46BD2D27509F9C83E4CD51D7A626D3D06E51E6FC1E45A99A3D5`.
- 로고 그림은 수정하지 않고 CSS 크기만 조정했다.
- 설치 아이콘은 기존 ProjectL2의 흰색 T + `#ff4804` 디자인을 코드 SVG/PNG로 재현했다. 생성 명령은 `node scripts/generate-ticgle-icons.mjs`다.

## 적용

- 헤더, 로딩, 로그인/비밀번호 재설정에 원본 워드마크 적용. 헤더 폭은 82px, 작은 화면은 74px. 로그인은 108px.
- 메뉴: `피드 / 티끌맵 / 끌렉션 / 스튜디오`.
- 개인 범위: `내 티끌`. 기록을 뜻하는 로그는 티끌로 변경. 로그인·로그아웃 같은 인증 용어는 유지하고 한국어 조사를 정리했다.
- 기존 개인 컬렉션은 끌렉션 보드와 구분되도록 `티끌 묶음`으로 표기한다.
- 등록/수정/검색/공유/캘린더/알림/알파 안내의 표현을 맞췄다. 실제 저장된 제목·본문은 변환하지 않는다.
- 시스템 포인트 색상을 기존 티끌 주황색으로 통일했다. 카드 안에는 브랜드 로고를 추가하지 않으며 사용자가 선택한 카드 팔레트도 유지한다.
- 브라우저 제목, 설치 이름, favicon/Apple icon/manifest icon을 적용했다.

## 유지하는 계약

기존 URL, manifest id `/`, start_url, scope, standalone 모드와 상태표시줄 설정은 유지한다. Supabase 프로젝트·테이블·인증·저장 키(`l2_unified_ui_v1`, `l2_unified_preview_session_v1`)·백업 내부 형식·알림 메시지 프로토콜은 변경하지 않는다. 옛 프로젝트는 읽기와 로고 복사만 했고 환경 파일이나 사용자 데이터를 가져오지 않았다.

설치 테스트 HTTP 검사는 이름/아이콘 변경을 허용하되 기존 설치 식별자와 scope/display 유지 여부를 검사하도록 정리했다. 기존 홈 화면 아이콘의 표시 이름·그림 갱신 시점은 OS에 따라 다를 수 있다.

## 검증

- 393×793 및 320×568: 헤더와 네 메뉴 가로 넘침 없음. 320px 헤더의 로고/범위/설치/설정이 각각 12–86 / 91–190.94 / 193.94–261 / 264–308px로 겹침 없음.
- 개인·모임 범위 선택, 티끌맵·끌렉션 이동, 라이트·다크 로고, 로그인/회원가입 전환, 티끌 등록 대상 선택창 확인.
- 예시 로그아웃/재진입 후 기존 기록과 끌렉션 배치 유지 확인. 실제 가입·비밀번호 변경·모임 공유는 실행하지 않았다.
- 첫 화면의 pinned=false와 리모콘 bottom 779.08px 유지 확인.
- 알파 보고서 7개, 알림 worker, 피드 초기화 13개, viewport 20개, 화면 스와이프 회귀 통과.
- 프로덕션 빌드 통과. 설치 메타 HTTP 12개, 제목과 워드마크 크기 및 PNG 아이콘 192/512/180px 확인.
- 로컬 화면: `.test-data/ticgle-feed-local.png`, `.test-data/ticgle-login-local.png`, `.test-data/ticgle-dark-local.png`.
