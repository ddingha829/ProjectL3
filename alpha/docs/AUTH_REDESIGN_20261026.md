# 로그인 화면 정리

- 회원가입 탭 대신 로그인을 기본 진입으로 표시한다. 하단 링크로 회원가입/로그인을 전환하고 입력한 이메일은 유지한다.
- 로그인 화면의 임시 L2 로고, 슬로건, 소개 헤드라인을 제거했다. 사용할 수 없는 Google 로그인 버튼도 숨겼다.
- 화이트/차콜 캔버스, 중립색 CTA, 얇은 입력선과 시스템 UI 폰트로 폼의 대비와 위계를 정리했다. 입력 글자는 16px를 유지한다.
- 알파 버전·이메일 인증 없음·백업 후 테스트 데이터 삭제 안내는 하단의 펼침 영역에 보존했다.
- MCP에서 shadcn login-01의 폼 구조와 Tween UI slide-arrow-button-demo를 확인하고, 기존 Tween 버튼을 중립색으로 맞춰 사용했다. 새로운 패키지는 설치하지 않았다.
- 인증 API·DB·이메일 인증 정책은 변경하지 않았다.

확인: 기본 로그인, 잘못된 이메일 포커스/오류, 회원가입 6자 미만 비밀번호 오류, 비밀번호 표시, 안내 펼침, 320px 모바일/1280px PC 배치, 라이트/다크, TypeScript/Next.js 프로덕션 빌드.

배포는 codex/unified-vercel Preview에만 적용한다.
