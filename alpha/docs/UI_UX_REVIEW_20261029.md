# 티끌 UI/UX 점검 및 제안

점검 기준: Production alpha-ceb8152, 2026-10-29. 예시 계정으로 393×793 주요 화면과 320×568 스튜디오를 직접 확인하고 관련 소스를 검토했다. 이번 작업은 검토만 진행했으며 제품 코드를 변경하거나 배포하지 않았다.

## 총평

카드 중심 피드, 주황색 브랜드, 일관된 하단 내비게이션은 유지할 가치가 있다. 추가 장식보다 처음 사용자가 기능을 이해하고 기록을 마치는 과정을 단순화하는 것이 우선이다.

## 우선 개선

| 우선순위 | 관찰 | 제안 | 확인 기준 |
|---|---|---|---|
| 높음 | 320×568 스튜디오에서 카드가 극단적으로 축소됨 | 카드 미리보기 최소 크기를 확보하고 설정 영역만 스크롤. 저장 버튼은 편집 패널 하단 고정. 필요하면 미리보기 확대 제공 | 작은 화면에서도 제목과 디자인 차이를 판단할 수 있고 저장 접근 가능 |
| 높음 | 글만 쓰기에서 편집창 접기 후에야 전체 닫기 버튼이 나타남 | 항상 보이는 뒤로가기와 명확한 작성 종료 동선. 내용이 있으면 임시 보관/계속 작성 선택 | 한 번의 명시적 동작으로 종료 의사를 표현하고 내용 유실 방지 |
| 높음 | 글쓰기창의 회색 안내와 투명 배경 조합이 희미하게 보임 | 카드 배경에 관계없이 입력 텍스트와 안내가 읽히도록 입력 패널 대비 확보 | 밝은 사진·어두운 사진·글 카드 각각 검증 |
| 중간 | 스튜디오와 작성 진입 때 안내 모달이 각각 행동을 중단함 | 설명 가능한 화면은 한 줄 인라인 도움말로 전환. 실제로 어려운 동작만 최초 1회 안내 | 신규 사용자가 안내 닫기 없이 첫 기록을 시작 |
| 중간 | 스튜디오 INSTA/TICKET/POLAROID와 프리셋 용어가 결과를 추측하게 함 | 사진형 / 티켓형 / 액자형, 저장한 디자인 등 쉬운 이름. 기존 그림 미리보기 유지 | 이름만으로 모양과 저장 범위를 이해 |
| 중간 | 끌렉션 미배치 0 상태가 넓은 패널을 사용하나 다음 행동은 없음 | 모두 배치한 상태는 한 줄로 축약. 작품이 아예 없으면 작품 기록하기 버튼 제공 | 비어 있음과 모두 완료 상태를 구분 |
| 중간 | 지도 위치 실패 안내가 확대/축소 주변을 덮고 안내가 재시도 중심임 | 간결한 상태 표시와 현재 표시 위치 설명. 권한 거부/위치 확인 실패를 구분하여 해당 복구 방법 안내 | 지도 조작을 가리지 않고 위치 실패에서도 기록 탐색 가능 |
| 중간 | 지도 하단에 가까운 로그/지도 안의 로그가 남아 있음 | 사용자 노출 명칭은 티끌로 통일. 지도 중심 기준은 보조 설명 유지 | 사용자 문구에서 로그·기록·티끌 혼용 최소화 |
| 중간 | 피드 보기/보관함은 아이콘 의미를 처음에 추측해야 함 | 현재 툴바 배치 유지. 최초의 짧은 라벨 또는 펼친 메뉴 제목으로 의미 보강 | 설명 모달 없이 보기와 보관함을 구분 |
| 중간 | 공유 형태 선택은 단계가 명확하지만 최종 결과 이미지를 바로 확인할 수 없음 | 준비된 이미지 작은 미리보기와 장수 표시. 선택한 형태 유지. 전송과 다운로드 버튼 구분 유지 | 앞뒤/합본의 실제 결과를 보내기 전에 확인 |
| 낮음 | 설정에서 예시 계정의 사용 불가능한 알림 옵션이 길게 노출됨 | 예시 계정에서는 로그인하면 사용 가능하다는 짧은 안내로 축약. 실제 계정 알림 배치 유지 | 불가능한 옵션이 주요 설정을 밀어내지 않음 |

## 화면별 추가 제안

- 피드: 빈 검색 결과에 검색어 지우기/필터 초기화 중 원인에 맞는 복구 동작 제공. 카드 크기와 현재 도크 위치는 유지한다.
- 모임: 헤더 범위 전환과 설정의 관리 역할 분리 유지. 등록 직전에 내 티끌/공유할 모임을 명확히 표시하는 것이 중요하다. 이번 검토에서는 실제 계정 등록·공유를 수행하지 않았다.
- 로그인: 소스상 알파 안내, 입력 라벨, 오류 상태, 비밀번호 보기, 처리 중 잠금이 있다. 실제 신규 가입 완료/복구 메일 수신은 이번 검토 범위가 아니다.
- 알림: 현재 UI는 근처 알림이 앱을 보는 동안 동작함을 명시한다. 백그라운드에서도 위치 알림이 항상 온다는 인상을 주지 않도록 안내를 유지한다.
- 접근성: 10~12px 보조 문구는 중요도에 따라 12~14px로 상향 검토. 아이콘 그림 크기와 별개로 터치 영역을 확보한다. 실제 VoiceOver, 큰 글씨, 다크모드 대비 수치, 동작 줄이기는 별도 검증이 필요하다.

## 권장 실행 순서

1. 작성 종료/입력 가독성 및 작은 화면 스튜디오.
2. 온보딩 축약, 끌렉션 빈 상태, 용어 통일.
3. 공유 미리보기와 피드 도구 발견성.
4. 실제 iPhone PWA에서 키보드·안전 영역·뒤로가기·카카오톡 수신 및 VoiceOver 검증.

## 검증 한계

데스크톱 브라우저의 모바일 크기 검사는 실제 iOS PWA 검증을 대체하지 않는다. 이번에는 실제 계정 데이터 변경, 게시, 공유 전송, 가입, 결제 또는 배포를 하지 않았다. 다크모드와 로그인 완료 흐름 등 직접 실행하지 않은 항목을 정상 판정하지 않았다.
