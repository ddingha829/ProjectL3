# L2 Archive · Test Version

리뷰 제안을 적용한 별도 실험 버전입니다. 원본 `ProjectL3/src`와 데이터는 변경하지 않습니다. 폴더 이름의 앞 `.`은 원본 TypeScript의 `**/*.ts` 검색과 분리하기 위해 사용했습니다. Windows 탐색기에서 일반 폴더처럼 열 수 있습니다.

## 실행

이 폴더에서 `npm run dev`를 실행하고 http://localhost:3013 을 엽니다. 같은 프로젝트의 부모 `node_modules`를 재사용합니다. 다른 곳으로 이 폴더만 옮길 경우 먼저 `npm ci`로 의존성을 설치하세요.

프로덕션 동작: `npm run build` 후 `npm start`. 오프라인 앱 셸 서비스 워커는 프로덕션 모드에서 활성화됩니다. 처음 온라인으로 한 번 열어야 오프라인 다시 열기를 사용할 수 있습니다. 서버가 실행 중이면 같은 포트로 두 번째 인스턴스를 실행하지 마세요.

## 적용한 변화

- 상위 메뉴는 `+ 로그 / 로그북 / 스튜디오`입니다. 카드는 로그북의 상세 화면입니다.
- 제목은 필수이고 포커스·입력 시 `제목 *` 라벨이 사라지며 굵고 크게 표시합니다. 기본 첨부는 사진·장소 두 가지, 별점과 추가 메모는 세부 설정에 모았습니다.
- 빈 로그 화면은 모바일 화면 높이를 채우고 저장 버튼을 화면 하단에 배치합니다. `무슨 일상을 로그할까요?` 문구와 움직이는 배경을 사용하며, 동작 줄이기 설정에서는 배경을 정지합니다.
- `로그 저장`을 누른 뒤 네 가지 분류를 선택하는 시트를 엽니다. 분류를 한 번 누르면 저장합니다.
- 사진 첨부 시 같은 메모 입력창이 사진 위에 배경 투명도 20%로 떠 있다가 스크롤에 따라 사진 아래로 내려옵니다. 동작 줄이기 설정에서는 처음부터 사진 아래에 표시합니다.
- 로그북은 텍스트 목록이 기본입니다. 검색 위에 따라오는 반투명 툴바에 분류·검색 / 보기·정렬·모음 만들기를 두 줄로 배치했습니다. 왼쪽 스와이프 삭제와 실행 취소를 지원합니다.
- 카드는 모바일에서도 두 열로 표시합니다. 모음 만들기에서 1~20개 로그를 선택하고 이름을 입력하면 `그룹` 로그로 저장하며, 그룹을 삭제해도 원본 로그는 남습니다.
- 스튜디오에서 기본 프리셋을 지정하면 새 기록에 적용합니다. 기록에는 디자인·비율·표시 옵션·팔레트·서명을 함께 저장하므로 이후 기본 프리셋을 바꿔도 기존 카드의 모양은 유지합니다.
- 카드 상세는 실제 카드, 저장한 프리셋 선택, 내용 수정·카드 저장·공유하기로 구성합니다. 내용 수정은 카드 위 시트에서 열고 같은 카드로 돌아옵니다. 세부 카드 편집기는 스튜디오에만 있습니다.
- 스튜디오는 높이에 맞춘 카드와 가로 프리셋 레일, 디자인/색상/세부 패널, 이전·다음 화살표로 구성합니다. 새 프리셋 추가와 명시적 저장을 제공하며 최대 20개를 보관합니다. 기본 프리셋 칩은 주황색입니다.
- KAKAO·INSTA·TICKET·LIST·TYPE·POSTER 기본 프리셋을 제공합니다. 수정하지 않은 구버전 기본 프리셋만 교체하고, 사용자 편집 프리셋과 기록의 스타일 스냅샷은 유지합니다.
- MAP은 Leaflet + OpenStreetMap 타일을 사용합니다. 지도 타일만 다크 필터로 처리하고 제목 핀, 선택 강조, 확대/축소, 전체 보기, 검색·분류 연동을 제공합니다. OSM 표기는 유지하며 타일을 오프라인으로 일괄 다운로드하지 않습니다.
- 장소 검색 결과의 실제 위도·경도를 기록에 보관합니다. 예전 mapX/mapY 값은 실제 좌표로 사용하지 않습니다. 좌표가 없는 예전 장소는 MAP의 `위치 연결`로 연결할 수 있습니다.
- 원문을 IndexedDB에 확정한 뒤 아카이브에 표시. 서버 동기화는 영속 outbox로 처리하고 실패/대기/재시도를 구분.
- 새 기록/수정 기록별 초안 복구, 저장 실패 시 내용 유지, 수정 시 경험 날짜 유지, 삭제 실행 취소.
- 카드/스튜디오/아카이브/설정 컴포넌트 및 저장/초안/스타일 훅 분리.
- 미리보기 우선 모바일 스튜디오, 양식·색·세부 패널, 20종 디자인과 3개 출력 비율, 21종 기본 팔레트와 3열 선택창, 프리셋 드래그 정렬·카테고리별 기본값, 비파괴 사진유무 레이아웃 결정. 추가 9종은 `DOCS/CARD_DESIGN_PROPOSALS.md`, 프리셋 관리·색상 조사·TMDB 수정은 `DOCS/PRESET_WORKFLOWS.md` 참고.
- 고정 420px 논리 캔버스: 3:4는 PNG 1260×1680, 1:1은 1260×1260, 9:16은 1260×2240.
- 폰트/이미지 준비 뒤 출력, 사용 폰트 서브셋 임베딩 캐시, 결정적인 PNG 그레인, 취소/실패 구분.
- 로컬 크롭 미리보기 후 한 번만 저장. 레이아웃별 표시 옵션 계약과 기요셰·괘선 수정.
- 저장 착지 애니메이션, 선택적 햅틱, reduced motion, 키보드 조작과 모달 포커스 관리.

## 격리와 외부 API

- 서버 데이터: 이 폴더의 `.test-data/`
- 쿠키: `l2_test_device`
- 브라우저 DB: `l2_test_archives_v1`, 원본 브라우저 데이터와 구분
- 주소: `localhost:3013`, 원본 3000/3001과 분리
- 원본 `.env.local`, Supabase 데이터, 실제 기록은 복사하지 않았습니다. 테스트 저장소는 항상 로컬 파일을 사용합니다.

OSM 지도 표시에는 Google 웹 지도 키가 필요 없습니다. Google 장소 검색은 이 폴더 자체의 `.env.local`에 `L2_TEST_ALLOW_EXTERNAL=true`와 `GOOGLE_MAPS_API_KEY`를 설정합니다. 허용된 기존 Places API에 맞춰 `GOOGLE_PLACES_API_MODE=legacy`로 연결했습니다. 결제 연결 후 실제 검색 결과 → 좌표 저장 → OSM 핀 표시까지 검증했습니다. Google 키는 서버에만 보관합니다. Gemini/TMDB 키와 Supabase 데이터는 가져오지 않았습니다. 자체 설정 외에 원본 환경변수를 자동으로 읽지 않습니다.

## 검증

현재 화면 구조와 사용자 흐름은 [IA·워크플로 문서](DOCS/IA_WORKFLOWS.md), 요청별 대응은 [적용 내역](DOCS/UX_CHANGELOG.md)에 정리했습니다.

`npm run typecheck`, `npm run test:repository`, 서버가 켜진 상태에서 `npm run test:ui`, `npm run test:map`, `npm run test:pwa`, `npm run test:motion`. 마지막 검증은 실제 Google 장소 검색을 1회 호출합니다.

모든 화면 폭에서 새 로그 입력 영역은 남는 화면 높이를 채웁니다. 설정의 움직임은 기기 설정 / 켜기 / 끄기를 제공합니다. 요청된 애니메이션을 새 브라우저에서도 확인할 수 있도록 테스트 버전의 기본값은 켜기입니다. 명시적으로 선택한 기기 설정 / 끄기는 재접속 후에도 유지합니다. 기기 설정은 OS의 동작 줄이기를 따릅니다. 기본 프리셋 지정은 별도 저장 없이 즉시 저장하고 목록 맨 앞으로 옮깁니다.

기본 자료가 없는 상태에서도 스튜디오에서 사진 있는 예시/글 중심 예시를 볼 수 있습니다. 예시 미리보기는 내 아카이브에 자동으로 저장하지 않습니다. TEST VERSION 표시와 연결 상태는 설정에서 확인할 수 있습니다.
